**Chemical Structures Cleaning Center**


While chemical database curation is an essential prerequisite for reliable computational modeling and QSAR analysis, most existing pipelines require programming expertise in Python or complex command-line setups. Chemical Structures Laundry Center was created to democratize this process—providing an automated, user-friendly, and open-access web platform that allows experimentalists, chemists, and chemoinformaticians alike to standardize and clean chemical datasets effortlessly without writing a single line of code.

Access to the tool: https://huggingface.co/spaces/Dannmarquez16/Chemical_Structures_Cleaning_Center

Chemical database requirements:

1. A column with the compounds' chemical linear representation in SMILES format.

2. The CSV file size can be up to 50 MB.

3. A column with the molecule name or an identifier is recommended.


The CSCC_test used to evaluate the curation web is available on the current repository. Also the curated_CSCC and the duplicates_files are available
